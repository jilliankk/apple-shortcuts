After downloading

  1. Tap Add Shortcut when prompted by the Shortcuts app
  2. Tap the shortcut name → Edit
  3. Find the Get Contents of URL step
  4. Tap the x-api-key header value and replace YOUR_CLAUDE_API_KEY_HERE with your key
  5. Tap Done
  6. Repeat for each shortcut, then add all three to Control Center in Settings → Control Center
